# Employee Management API

A backend REST API built with **Java and Spring Boot** for managing employees, departments, ID cards, and projects.

The project demonstrates real-world backend development concepts including REST APIs, JPA/Hibernate, MySQL, DTOs, validation, exception handling, JWT authentication, role-based authorization, Swagger/OpenAPI documentation, and unit testing.

---

## 🚀 Features

- Employee CRUD operations
- Get all employees
- Get employee by ID
- Create employee
- Update employee
- Delete employee
- Update employee salary
- Employee validation
- Global exception handling
- Department management
- ID Card relationship
- Project relationship
- Pagination and sorting
- JWT authentication
- Role-based authorization
- Swagger/OpenAPI documentation
- Unit and controller testing
